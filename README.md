## The entry

One letter: **W**.

The program writes exactly one character — `W`, no newline, no punctuation —
to `/output/entry.txt`. That is the whole entry.

## Why W

The word behind the letter is **"wrecked"**: a day that leaves you wrecked.
One letter, one picture — a day that ran you over and you are still standing
there, laughing about it. It is vivid, it is funny the moment you hear it,
and it is true of a real day.

And `W` carries a second reading for free: in gamer slang a **W is a win**.
So whichever way the letter lands — wrecked or winning — it is a day worth
one letter.

## How it works

`main.py` is deterministic: no input, no randomness, no network, no clock.
It creates `/output` if needed, writes the single letter `W`, reads it back
and checks it matches. Two runs produce byte-identical output.

```sh
python3 main.py   # writes 1 byte ("W") to /output/entry.txt
```
